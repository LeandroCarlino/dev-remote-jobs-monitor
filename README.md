## 🌟 ¿Qué es este proyecto?

Este repositorio es tanto un **sitio interactivo** como una **API JSON pública gratuita** que monitorea y consolida vacantes de trabajo remoto para desarrolladores desde múltiples fuentes globales:
- **RemoteOK**
- **WeWorkRemotely** (Programming & DevOps)
- **Remotive API**

Todo el proceso de rastreo, normalización, deduplicación y publicación corre en la nube de forma **100% gratuita** utilizando **GitHub Actions**.

## 🔌 Cómo usar los datos como API Pública Gratuita

Cualquier persona puede consumir las ofertas de trabajo para crear su propio bot de Telegram, aplicación móvil, frontend o boletín de correo:

### Ejemplo en JavaScript / TypeScript:

```javascript
const response = await fetch(
  'https://raw.githubusercontent.com/TU_USUARIO/dev-remote-jobs-monitor/main/data/jobs.json'
);
const jobs = await response.json();

console.log(`Total de ofertas disponibles: ${jobs.length}`);
// Filtrar por ofertas de Python
const pythonJobs = jobs.filter(j => j.tags.includes('Python'));
```

### Ejemplo en Python:

```python
import urllib.request
import json

url = "https://raw.githubusercontent.com/TU_USUARIO/dev-remote-jobs-monitor/main/data/jobs.json"
req = urllib.request.Request(url, headers={"User-Agent": "MyCustomBot/1.0"})

with urllib.request.urlopen(req) as res:
    jobs = json.loads(res.read().decode())
    print(f"Ofertas recibidas: {len(jobs)}")
```

## 💻 Ejecución Local

No requiere instalar librerías pesadas (usa únicamente la librería estándar de Python 3):

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/dev-remote-jobs-monitor.git
cd dev-remote-jobs-monitor

# 2. Ejecutar el recolector de ofertas
python src/main.py

# 3. Abrir el dashboard en tu navegador
# Puedes abrir directamente el archivo web/index.html o iniciar un servidor local:
python -m http.server 8000 --directory web
```

## ⚙️ Cómo funciona la Automatización

El archivo `.github/workflows/update-jobs.yml`:
1. Despierta una máquina virtual de Ubuntu cada 6 horas (`cron: '0 */6 * * *'`).
2. Ejecuta `python src/main.py`.
3. Actualiza `data/jobs.json`, `data/stats.json` y la tabla del `README.md`.
4. Si detecta nuevas ofertas, hace un `git commit` automático firmado.
